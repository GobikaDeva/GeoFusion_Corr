# DTU split lists

Place the standard MVSNet-family split lists here, one scan id per line:

- `dtu_train.txt`
- `dtu_val.txt`
- `dtu_test.txt`

Using the exact split used by the reference GeoMVS baseline is a **Stage 0
requirement** (docs/baseline_recovery_plan.md) — do not substitute a different split
without re-establishing the baseline number first.
